读取与消费

所有发布物均为静态 JSON，读取不经 Worker 计算；直接以 HTTP GET 拉取即可， 无需鉴权、不消耗请求配额，可放心配合缓存与镜像使用。

端点清单

端点说明缓存层
/index.json平台目录索引（数据集清单与当前版本）index
/search/index.json跨数据集静态搜索索引（数据集名称 / 字段 / 数据正文）index
/{slug}/manifest.json数据集清单：Schema 版本、数据版本、latest / previewindex
/{slug}/latest.json最新正式版指针pointer
/{slug}/preview.json预览指针（非正式）pointer
/{slug}/versions/{v}.json不可变数据快照immutable
/{slug}/search-index.json单数据集搜索文档index
/schemas/{slug}/{v}.json冻结的 JSON Schemaimmutable

静态 JSON 消费方式

典型读取流程：先读目录索引导航，再按 slug 读清单，最后读指针指向的不可变快照。

// 1) 目录
fetch("/index.json").then((r) => r.json());

// 2) 数据集清单
fetch("/demo/manifest.json").then((r) => r.json());

// 3) 最新正式快照（版本号来自 manifest.latest）
fetch("/demo/versions/3.json").then((r) => r.json());

快照路径一经发布即不可覆盖，可安全配合长缓存与 ETag 做本地镜像； 指针文件短缓存并强制回源校验，用于发现新版本。

缓存分层

  • immutable：版本快照与冻结 Schema，max-age=31536000, immutable。
  • pointer：latest / preview 指针，max-age=60, must-revalidate。
  • index：目录与搜索索引，max-age=300。

已发布数据以 latest.json 指向的不可变快照为准；预览（preview.json）为 非正式产物，请勿作为数据来源。
