读取与使用数据

兰台把每个数据集以静态 JSON 发布在固定网址上。任何人都可以直接用浏览器打开、下载， 或在程序里按网址读取——无需注册，也无需密钥。

可用地址

地址用途
/index.json平台数据目录：有哪些数据集、各自当前版本
/search/index.json搜索索引：数据集名称、字段与数据内容
/{slug}/manifest.json某数据集的清单：Schema 版本、全部数据版本与最新版
/{slug}/latest.json指向该数据集最新的正式版数据
/{slug}/versions/{v}.json某个固定版本的数据，发布后内容不再变化
/schemas/{slug}/{v}.json该数据集的字段定义（Schema）

怎样读取

先读目录找到数据集，再按 slug 读它的清单，然后取最新版本的数据。

// 1) 平台目录：有哪些数据集
fetch("/index.json").then((r) => r.json());

// 2) 某数据集的清单：Schema 版本与数据版本
fetch("/demo-population/manifest.json").then((r) => r.json());

// 3) 取最新正式版数据（版本号来自清单的 latest）
fetch("/demo-population/latest.json")
  .then((r) => r.json())
  .then((m) => fetch(`/demo-population/versions/${m.dataVersion}.json`))
  .then((r) => r.json());

怎样确认拿到的是最新版

  • 清单 manifest.json 的 latest 字段，指向当前最新的正式版本号。
  • 版本数据 /versions/{v}.json 一经发布就不再改动，可长期引用同一个网址。
  • 只想取「最新」时，先读 latest.json，再按其中的版本号取对应版本。

preview.json 是非正式的预览数据，请勿作为数据来源。
