匿名贡献与审阅流程

任何人均可匿名提交数据修订，无需账号。提交经人机校验与限流门槛后进入审阅队列， 由管理员预发布与合并；发布后即以新的不可变快照生效。

总览 读者 贡献者 运营者

提交流程

  1. 在 提交页选择数据集，并粘贴符合该数据集冻结 Schema 的 JSON。
  2. 通过 Turnstile 人机校验（生产环境）与限流后入库，状态为 pending。
  3. 系统返回一次性追踪令牌；如填写邮箱，将收到状态通知。

提交前请核对字段名称、类型与必填项；提交页会读取冻结 Schema 并给出字段提示。

状态机

pending ──▶ staged ──▶ published
   │           │
   └───────────┴──────▶ rejected

published 为终态；rejected 保留记录并在保留窗口后将 payload 置空。 所有状态迁移均写入审计。

追踪与通知

凭追踪令牌查询状态：

GET /api/submissions/{token}
→ { "slug": "demo", "status": "pending", ... }

也可在进度查询页输入令牌查看当前状态与后续步骤。

通知邮件仅包含追踪令牌与查询链接，绝不回显 payload 等敏感内容； 未配置邮件通道时静默跳过，不影响提交结果。
