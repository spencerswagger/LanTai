开放接口

兰台把公开数据发布为静态 JSON：读取直接走 CDN、绕开 Worker、零计算；写入与审阅经 Worker 处理。 本页汇总四种角色的使用文档与全部开放接口，供你按需取用。

平台概览

兰台是公开数据的发布与共享平台。每个数据集都以不可变 JSON Schema 编目，发布为数据集级不可变快照， 因此同一版本的内容永不改变，可被安全地缓存与镜像。

任何人无需账号即可匿名提交符合 Schema 的数据；管理员审阅后预发布并正式发布，新的快照随即生效。 读取路径不消耗计算配额，写入与审阅才经 Worker。

开放接口一览

接口方法说明
/index.jsonGET数据目录索引：数据集清单与当前版本
/search/index.jsonGET跨数据集搜索索引（数据集名称 / 字段 / 数据正文）
/{slug}/manifest.jsonGET数据集清单：Schema 版本、数据版本、latest / preview
/{slug}/latest.jsonGET最新正式版指针
/{slug}/preview.jsonGET预览指针（非正式）
/{slug}/versions/{v}.jsonGET不可变数据快照
/schemas/{slug}/{v}.jsonGET冻结的 JSON Schema
/api/submissionsPOST匿名提交数据，返回追踪令牌
/api/submissions/{token}GET凭追踪令牌查询提交状态
/api/healthGET服务健康检查

公开读取无需鉴权、不消耗请求配额。写入与审阅接口受 Cloudflare Access 保护，未登录返回 401。

/index.json 是什么

它是机器可读的数据目录索引——一份静态 JSON 文件，不是网页。 用浏览器直接打开只会看到原始 JSON，这是有意设计：CDN 直读、零计算，便于脚本与镜像消费。 人类阅读请改用数据目录页。

generatedAt
索引生成时间（ISO 8601）
datasets
已发布数据集数组
datasets[].slug
数据集标识，用于拼出 /{slug}/manifest.json
datasets[].title
数据集标题
datasets[].currentSchemaVersion
当前冻结的 Schema 版本
datasets[].currentDataVersion
当前已发布的数据版本（可能缺省）
datasets[].updatedAt
最近更新时间

取用示例

先读目录索引，再按 slug 读清单，最后读指针指向的不可变快照：

curl -s https://<站点域>/index.json

# 依 datasets[].slug 读取清单
curl -s https://<站点域>/{slug}/manifest.json

# 依 manifest.latest 读取不可变快照
curl -s https://<站点域>/{slug}/versions/{version}.json

完整端点、缓存纪律与读取流程见读者指南。
